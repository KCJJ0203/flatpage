# Flatpage

Photograph a page, flatten it, get a clean PDF. On your device, nothing uploaded.

No account. No cloud. No watermark. No ads.

- Design: `docs/superpowers/specs/2026-08-19-flatpage-design.md`
- Plan: `docs/superpowers/plans/2026-08-19-flatpage-v1.md`
- Findings from measurements: `docs/findings/`

## Development

    npm test        # runs the pure-module tests under node --test

There is no build step. Open `index.html` over HTTPS (GitHub Pages) to run it.
